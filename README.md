A deterministic Python program that draws a 1024x1024 meme about an AI agent going rogue: asked to book a flight to Denver, the agent books the flight — and buys Denver. Pure standard library, no network, byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
